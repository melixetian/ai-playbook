# AI Playbook

[English](#english) · [Русский](#русский)

## English

AI Playbook is a compact, evidence-aware knowledge base for developers and AI agents. It explains how to configure an agent-friendly development environment, write effective prompts and reusable skills, manage context and permissions, and verify results.

### Documents

- [AI Agent Configuration Playbook](Playbook.md) — instructions for agents that configure or improve a development repository.
- [Two Grammars in One Evening — Russian](Grammar.md) — a linguistic framework for prompts and skills.
- [Two Grammars in One Evening — English](Grammar.en.md) — the synchronized English edition.
- [`history/`](history/) — non-normative Playbook snapshots retained for historical context.

The project distinguishes stable principles, product-specific guidance, research evidence, and local heuristics. Volatile claims are dated and should be rechecked against primary sources and realistic evals.

The original Grammar framework and research are by Yuri Zelenkov. The public edition was compiled and edited by Meliksetian Narek and is published with Yuri Zelenkov’s permission.

## Русский

AI Playbook — компактная база знаний для разработчиков и ИИ-агентов, построенная с учётом качества доказательств. Она объясняет, как настраивать удобное для агента окружение разработки, писать точные промпты и переиспользуемые скиллы, управлять контекстом и правами и проверять результат.

### Документы

- [AI Agent Configuration Playbook](Playbook.md) — инструкция для агента, который настраивает или улучшает репозиторий разработки.
- [«Две грамматики за один вечер» — русская версия](Grammar.md) — лингвистический подход к промптам и скиллам.
- [«Две грамматики за один вечер» — английская версия](Grammar.en.md) — синхронизированная английская редакция.
- [`history/`](history/) — ненормативные снимки предыдущих версий Playbook, сохранённые для истории.

Проект разделяет устойчивые принципы, особенности конкретных продуктов, результаты исследований и локальные эвристики. Нестабильные утверждения датируются и должны перепроверяться по первичным источникам и реалистичным evals.

Автор исходной концепции и исследования Grammar — Юрий Зеленков. Публичную версию составил и отредактировал Меликсетян Нарек; материал опубликован с разрешения Юрия Зеленкова.
